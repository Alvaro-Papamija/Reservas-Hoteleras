# Especificación de Requisitos de Software (SRS — IEEE 830)

El documento oficial y completo de Especificación de Requisitos de Software para el **Sistema de Gestión y Reservas Hoteleras — Hotel Grand Imperial**, estructurado bajo los estándares internacionales **IEEE Std 830-1998** y **ISO/IEC/IEEE 29148:2018**, se encuentra disponible en:

- [**docs/SRS_IEEE_830_GRAND_IMPERIAL.md**](./SRS_IEEE_830_GRAND_IMPERIAL.md)

### Resumen de Secciones:
1. **Introducción:** Planteamiento del problema de sobreventa, justificación, vigilancia tecnológica (OTAs vs PMS), objetivos y alcance.
2. **Descripción General:** Arquitectura de 3 capas, perfiles de usuario (RBAC) y restricciones.
3. **Requisitos de Interfaces Externas:** UI/UX hotelera, hardware, software y comunicaciones HTTPS/JSON.
4. **Historias de Usuario (HU-01 a HU-25):** Backlog ágil con criterios Gherkin (BDD) y estimación en Story Points.
5. **Modelado UML:** Diagrama general de casos de uso en Mermaid y relaciones `<<include>>`/`<<extend>>`.
6. **Catálogo de Requerimientos Funcionales (RF-01 a RF-25):** Fichas técnicas completas con entradas, salidas, manejo de excepciones y criterios verificables.
7. **Requerimientos No Funcionales (RNF-01 a RNF-10):** Fichas de atributos de calidad con métricas cuantitativas y efectos colaterales.
8. **Reglas del Negocio (RN-01 a RN-14):** Formalización matemática de solapamiento de fechas, capacidades, pagos y auditoría.
9. **Matriz de Trazabilidad y Vacíos de Información (TBD):** Mapeo integral y decisiones técnicas pendientes.
